# Security policy

This project evaluates text offline and does not execute commands from events. Treat event content and custom rule files as untrusted until reviewed. It is not hardened for hostile multi-gigabyte input or untrusted regular expressions.

For a vulnerability, use GitHub's private vulnerability reporting option if enabled. If unavailable, open a minimal issue asking the maintainer for a private reporting channel without exploit details, secrets or customer data. No private reporting endpoint or response-time guarantee is currently configured.

Version 0.1.x is the current experimental release line. Fixes are best effort. Production deployments require their own security review.
